# Experiment Records

Commit small, machine-readable summaries and experiment cards here. Do not commit datasets or checkpoints.

Every accepted experiment should include:

- hypothesis and comparison budget
- git commit
- complete config
- seed(s)
- hardware/software environment
- metric protocol and sample count
- result table
- failure/alternative-explanation notes
- artifact/checkpoint hashes or external immutable links

Copy `template.md` for a new experiment.
